# JavaScript interview path (Frontend, ~3 years)

Order we will follow. Do not skip ahead until the exercise for that lesson is done.

1. Values, types, `let` / `const` / `var`
2. Operators, coercion, `==` vs `===`
3. Functions, parameters, `this` (intro)
4. Scope, hoisting, closures
5. Objects, arrays, references vs copy
6. Prototypes, classes
7. Async: callbacks, promises, async/await, event loop
8. ES6+: destructuring, spread, modules, optional chaining
9. Array methods, map/filter/reduce (interview favourite)
10. DOM + events (light; then React)
11. Common output-based questions (mix)

Current company stack to keep in mind: React, Next.js, TypeScript, Redux, Zustand.
